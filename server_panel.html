Supabase
Tables

Click a cell and type; press Enter to save instantly (Tab / arrows move between cells). Every change is logged and a copy of what was replaced is kept in the changes log. The password column is hidden: type a new value to replace one.

Projects — one server, one address, one database per project

Every project gets its own database file and its own keys, but they all use this server’s single tunnel address. Websites reach a project at <your address>/w/<project>.

Table editor

Browse and edit rows like a spreadsheet. Click a cell to change it, press Enter to save.

An id and a created_at column are added automatically.

Use it from a website

Every table gets a ready API. Pick a project and table above, then copy this into your site.

SQL console

Works on any project’s database. It only reads unless you tick “Allow changes”; a backup copy is made before every change. This console exists only on this PC — it is never reachable through the tunnel.
